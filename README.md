# dotfiles-claude

个人觉得最好用的 Claude Code 轻量配置

## Skills

- **code-comments** — 注释只说代码说不出的 why，禁止装饰性和复述式注释；可扫描当前改动或整个项目并清理
- **code-naming** — 命名一眼可懂，禁止填充词、动作链、实现细节入名；可扫描并安全重命名
- **grilling** — 反复拷问计划、决策或想法，帮你压力测试思考
- **no-afterimage** — 要求"不要香菜"就端出一碗拉面，而不是"拉面（无香菜版）"或一条断言没有香菜的测试；扫描并清除会话指令留在成品里的残影
- **quality-tests** — 只写失败时能定位问题的测试，禁止镜像实现和空断言；新测试先看它失败一次
- **readme-writer** — 先从仓库收集事实并验证命令，再面向真实读者写 README
- **slopscan** — 扫描 AI 生成代码的反模式（吞错、伪造默认值、创可贴补丁、死代码等），按严重度报告并修正

## 安装

```bash
cp -r skills/* ~/.claude/skills/
```
